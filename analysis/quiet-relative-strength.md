# 怎么发现「大盘跌、它还在慢慢涨」的票

要的不是涨停板里最吵的那一类，而是：指数收阴时它仍收红（或至少明显抗住），K 线每天只走几个点，换手低，看起来像有人在慢慢买，而不是一天打满情绪。

涨停、高换手、龙虎榜是另一套玩法。下面这套专门对着「悄悄慢涨」。

## 先把现象写成可检查的条件

同时满足这四条，才算这一类：

1. **逆势**：看的是指数阴线日，不是阳线日。指数那天跌，它当天还是收红。
2. **慢**：上涨日的平均涨幅大约 0.3%–4.5%，窗口内单日不超过 7%，也不准靠近涨停（主板 9.5%、创业板/科创 19.5% 一带直接剔除）。
3. **静**：窗口内日均换手大约 0.15%–4.5%，量不能突然比这 15 天的均量高出一倍。
4. **还在走**：这 15 天价格净上涨、收盘还在 10 日均线上方、回撤不太深。只抗跌但不涨的，不算。

「不管大盘每天怎么跌都要涨」在 15 个交易日里，落实成：**指数真正收阴的日子里，至少 60% 它是红的，而且这些阴线日上它的平均收益 > 0。**

指数默认用沪深300（`sh000300`）。也可以改成上证 `sh000001` 或创业板 `sz399006`。指数涨跌不足 0.3% 的日子当成震荡，不计入「阴线日」，免得噪声把名单洗乱。

## 为什么不能只用「低换手」或「今天红」

低换手里有大量阴跌的大盘股，只是没人交易。今天收红、换手 1%，也可能是大盘本身就是红的。要的是：**大盘特意在跌的那些天，它还在买得动、又买得不凶。**

所以顺序是：

```
全 A（去掉 ST / 北交所 / 过小流通）
  → 先丢掉明显高换手、涨停、新股乱跳
  → 取出最近 15 日里指数阴线日
  → 统计这些日子里个股红盘比例、平均超额
  → 再检查慢、静、回撤、均线
  → 按分数排序
```

分数偏向：阴线日红盘比例高、相对指数超额大、上涨日涨幅落在 1%–3%、换手更低、回撤更浅、量能平稳。

## 每天开盘前/收盘后怎么用

**收盘后（主用法）**

```bash
python3 -m screener --index sh000300 --days 15 --top 40
python3 -m screener --max-nmc-yi 200 --exclude-re '银行|证券|保险'
```

看 `analysis/data/quiet-rs-latest.csv` 里的：

| 列 | 含义 |
| --- | --- |
| `rs_up_rate` | 指数阴线日里，它收红的比例（越高越「不管大盘」） |
| `rs_mean_pct` | 这些阴线日上它的平均涨跌 |
| `rs_excess_pct` | 相对指数的平均超额 |
| `avg_up_pct` | 它自己上涨日的平均涨幅（「几个点」） |
| `avg_turn_pct` | 窗口日均换手 |
| `max_up_pct` | 窗口内最大单日涨幅（用来抓漏网的冲高） |
| `max_dd_pct` | 窗口最大回撤 |
| `score` | 上面这些的综合 |

先看 `rs_up_rate` 和 `avg_turn_pct`，再看 `avg_up_pct` 是不是真的只有几个点。分数只是排序，不是推荐。

**盘中（指数已经翻绿时）**

同一套还有一道当日门：指数这天跌超过 0.3%，个股涨 0.25%–4.5%，换手仍在 0.15%–4.5%，且离涨停还有距离。结果写在 JSON 的 `today_quiet_if_index_down`。指数收平或收红时这张表会是空的，这是预期行为。

## 找到之后还要自己看的

程序只能看价格和量。名单出来后仍建议人工看：

- 有没有公告、解禁、回购、股权激励在支撑（「慢慢涨」有时只是事件）
- 是不是板块里唯一的红，还是行业本身在逆势（行业强和个股强要分开）
- 日 K 是小实体连阳，还是每天上影很长（后者不像被吃进）
- 流通盘是否大到「悄悄」两个字还说得通；盘子极小的低换手没有意义

## 这套刻意排除什么

- 涨停、连板、换手 10%+ 的情绪票
- 跟着指数一起阴跌、只是换手更低的蓝筹
- 窗口内先大跌再反弹、净收益还是负的票
- 北交所、ST

它们都可以单独做筛选，只是不是这个问题要的东西。

## 局限

15 个交易日很短，阴线日可能只有 4–6 根，比例会被单日打歪。流通股本用的是当日快照，窗口内若有解禁，换手会算高一点。没有基本面、没有资金流逐笔。输出不是买卖建议。

## 2026-08-25 扫描（沪深300，近 15 日）

窗口内沪深300 有效阴线日：8/11、8/13、8/18、8/19（−2.90%）、8/24。全 A 预筛后 4319 只，过硬条件 **57** 只。当天沪深300 只跌 0.24%，不到 −0.3% 门槛，所以「当日逆势安静红」名单是空的。

前排大量是银行、电力、煤炭——8/19 成长杀跌时，钱在往这类低换手头上走。这不是程序偏好金融，是这半个月里真正满足「阴线日还红、每天一两个点、换手不到 2%」的票就长这样。
