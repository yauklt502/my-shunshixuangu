# 妖龙跟随策略 v1.0（规则引擎版）

> **免责声明**：本文档与代码仅为公开市场规律的结构化复盘与研究框架，**不构成任何投资建议**。短线博弈亏损概率极高，据此操作风险自担。

## 0. 策略目标

把「跟随市场、跟随资金」从口号拆成**无情绪可执行规则**：

1. **先锁环境**（情绪周期）→ 决定仓位上限  
2. **再锁主线**（题材是否国家级、新/大/硬）→ 决定是否开仓  
3. **再锁龙头**（辨识度、高度、梯队）→ 决定标的唯一性  
4. **再锁资金**（龙虎榜真合力 / 换手健康）→ 决定是否值得跟  
5. **最后锁买点**（一进二 / 断板首阴 / 分歧转一致）→ 决定何时进  
6. **用硬止损与降级规则离场** → 决定何时走  

核心原则：**不预判谁会成妖，只在市场给出「成妖概率抬升」的证据后再跟随；证据消失立即退出。**

## 1. 近一年妖龙共性（2025.08 — 2026.08 复盘摘要）

### 1.1 样本画像（结构性结论）

| 维度 | 近一年高频特征 | 规则化阈值 |
|------|----------------|------------|
| 流通市值 | 多数启动时落在 **20–200 亿**，流畅连板更集中在 **40–80 亿** | `circ_mv ∈ [20, 200]`，最优 `[40, 80]` |
| 题材 | AI算力/PCB、机器人、绿电/央改、半导体、商业航天、重组控制权变更 | 必须挂靠当期**主线**，小题材弃 |
| 启动位置 | 低位横盘蓄势后启动，极少从历史高位直接成妖 | 相对 60 日低点启动溢价 < 40% 更优 |
| 走势骨架 | 低位横盘 → 放量首板 → 换手连板 → 高位爆量分歧 → 断板/见顶 | 分阶段交易，不做全程死拿 |
| 换手 | 健康连板日换手常见 **8%–25%**；>35% 多为高位出货或做T噪声 | `turnover ∈ [8, 25]` 加分；`>35` 减分/禁追 |
| 龙虎榜 | 一线游资多席位真合力；警惕单席位畸高 + 关联席位对倒 | 买一五分布均匀且知名席位≥2 |
| 监管环境 | 2025 下半年高度可冲 12–17 板；2026 中后段非 ST 高位更易遇监管压制 | **动态天花板**：用近 20 日市场最高板×0.7 作「危险区」 |
| 情绪 | 冰点→修复→升温→高潮→降温→退潮循环明显 | 仓位随阶段切换，高潮减仓、退潮空仓 |

### 1.2 近一年代表性「空间板 / 妖龙」骨架

| 标的（示意） | 主线 | 典型高度/涨幅特征 | 可抽象的共性 |
|--------------|------|-------------------|--------------|
| 锋龙股份 | 机器人/入主 | 年初级别空间板 | 硬题材 + 低位启动 + 辨识度最高 |
| 嘉美包装 | 控制权变更 | 年初 17 板级 | 重组叙事 + 小盘 + 情绪高潮期 |
| 天普股份 | 重组+机器人 | 2025.09 15 板级 | 政策/资产运作叠加 |
| 胜通能源 | 机器人+控制权 | 跨年 12 板级 | 跨年情绪窗口 |
| 利通电子 / 华电辽能 / 杭电等 | 算力/绿电 | 2026 趋势妖 + 连板妖并存 | 主线业绩逻辑更重于纯概念 |
| 国晟科技等 | 光伏/固态等 | 涨停次数极多的「反复妖」 | 高波动，跟的是波段不是信仰 |

### 1.3 K 线生命周期形态（必须按阶段看，不要混用买点）

```
启动期          加速期              见顶/退潮期
─────          ─────              ──────────
横盘缩量        换手连板            高位天量
放量首板  →    分歧→一致  →       长上影/天地板
均线多头        缩量加速板          断板后反包失败
```

| 阶段 | K线/量价特征 | 允许动作 |
|------|--------------|----------|
| 启动 | 首板放量、突破平台、封单真实 | 观察 / 轻仓一进二 |
| 加速 | 日换手 8–25%、炸板回封、板块跟风增多 | 只做龙头，仓位可控 |
| 高潮 | 市场最高板抬升、跟风一字增多 | **降仓**，禁追后排一字 |
| 见顶 | 历史天量、长上影、龙虎榜卖盘主导 | 只卖不买 |
| 首阴 | 缩量/平量阴线 + 新席位承接 + 站稳 5/10 日线 | 允许「龙头回首」低吸 |
| 退潮 | 高标大面、晋级率塌方 | 空仓或极轻试错 |

### 1.4 龙虎榜席位规律

**真合力（可跟）**

- 买方前五：席位分散，单席买入占比通常 < 40%
- ≥2 个一线/半一线名游资同向
- 前一日买方次日未集体砸出（锁仓或温和做 T）
- 换手落在健康区间，非无量一字后突然爆量

**假点火（禁追）**

- 单席位买入占比畸高（>50%）且次日大额卖出
- 买卖两端同一帮系对倒（拉萨军团等双向做 T 制造活跃假象）
- 「一日游」席位独舞，无接力
- 爆量烂板（换手 >30% 且收盘未回封）

**席位使用原则**：席位是**确认项**，不是选股项。先确认主线龙头，再用席位验证资金质量。

## 2. 「如何快速锁定」——三层漏斗（当日 15 分钟复盘 SOP）

### Layer A｜市场环境（2 分钟）

计算当日情绪标签（见引擎 `emotion.py`）：

- 涨停家数、跌停家数、最高连板、晋级率（昨 N 板→今 N+1）
- 昨日连板晋级率 < 30% → 偏弱；> 50% → 偏强
- 输出：`ICE / REPAIR / WARM / CLIMAX / COOL / EBB` + **仓位上限**

### Layer B｜主线与龙头（8 分钟）

1. 统计涨停池按题材聚类，取涨停数 Top3 题材  
2. 每个题材内按规则打分选 **唯一龙头候选**（不可同时跟 3 只「龙头」）  
3. 硬过滤：ST（默认剔除）、一字后排、非主线、市值越界  

龙头辨识度打分要点：

- 最先启动 / 连板高度最高 / 板块内辨识度最强 / 抗跌最优 / 媒体与资金讨论集中

### Layer C｜资金与买点（5 分钟）

对唯一龙头检查：

1. 今日是否换手板（非无量一字后排）  
2. 龙虎榜是否真合力（若当日上榜）  
3. 是否触发买点状态机（见下）  

**输出清单每天最多 1–2 只，超过说明你在选股而非跟龙头。**

## 3. 完整交易状态机（如何「追」资金）

「追」≠ 追涨停封单。正确的追法是：**追主线龙头的接力窗口**。

### 3.1 允许的三种买点（按优先级）

| 代码 | 名称 | 触发条件 | 仓位建议 |
|------|------|----------|----------|
| B1 | 一进二 | 昨首板；今竞价强/开盘不弱；题材升温；市值合格 | 情绪 WARM 起，≤仓位上限×0.5 |
| B2 | 分歧转一致 | 连板中盘中炸板或大分歧，尾盘回封或次日低开快速拉回 | ≤仓位上限×0.4 |
| B3 | 断板首阴低吸 | 总龙头首次断板收阴；缩量/平量；站稳 5/10 日；榜有承接 | ≤仓位上限×0.3，且非 EBB |

**明确禁止**

- 追后排一字、补涨跟风、高潮末期第 N 高标盲追  
- 单席位假点火次日接力  
- 换手 >35% 的高位天量阳线追入  
- 情绪 ICE/EBB 时新开仓（仅允许极少数「冰点首板试错」且仓位≤5%）

### 3.2 卖点 / 降级（无商量）

| 代码 | 条件 | 动作 |
|------|------|------|
| S1 | 收盘跌破 5 日线（持仓 ≥2 日） | 减半或清仓 |
| S2 | 高位天量长阴 / 天地板 | 次日竞价或开盘清仓 |
| S3 | 龙头辨识度被替代（被更高辨识度票反超） | 切换或离场 |
| S4 | 龙虎榜由真合力转假点火/一日游砸盘 | 离场 |
| S5 | 情绪进入 COOL/EBB | 只出不进，持仓逐日降仓 |
| S6 | 触及监管异动/停牌传闻核实 | 立即降级为观察，不博弈 |

### 3.3 仓位矩阵（情绪 × 买点）

| 情绪 | 总仓上限 | B1 | B2 | B3 |
|------|----------|----|----|-----|
| ICE | 5% | 试错 | 禁 | 禁 |
| REPAIR | 20% | ✓ | 谨慎 | 禁 |
| WARM | 40% | ✓ | ✓ | ✓ |
| CLIMAX | 25% | 减 | 谨慎 | ✓（更优） |
| COOL | 10% | 禁 | 禁 | 谨慎 |
| EBB | 0% | 禁 | 禁 | 禁 |

## 4. 量化评分卡（0–100，用于快速锁定）

总分解构：

```
Score = 0.20*Theme + 0.15*MCap + 0.20*Leader
      + 0.15*Volume + 0.15*Seat + 0.15*Pattern
```

| 子项 | ≥80 含义 | <60 处理 |
|------|----------|----------|
| Theme | 国家级主线 + 新大硬 | 直接剔除 |
| MCap | 40–80 亿甜点 | 越界剔除或大幅降权 |
| Leader | 题材内唯一最强辨识度 | 非龙头不做 |
| Volume | 换手健康、量价匹配阶段 | 天量/无量异常降权 |
| Seat | 多席位真合力 | 假点火一票否决当日追高 |
| Pattern | 处于启动/加速合法形态 | 见顶形态禁买 |

**开仓阈值建议**：`Score ≥ 75` 且情绪允许且买点触发。

## 5. 日常执行清单（可打印）

**盘前（20 分钟）**

1. 标注昨日情绪与今日预期仓位上限  
2. 列出昨日涨停池主线 Top3 + 各题材龙头  
3. 对候选龙头标注：连板高度、换手、是否一字、有无催化剂  

**盘中（只看计划内票）**

1. 不临时找票；只执行 B1/B2 计划  
2. 炸板回封才考虑加，烂板不补  

**盘后（30 分钟）**

1. 更新情绪标签与晋级率  
2. 复盘龙虎榜：真合力 / 假点火  
3. 刷新明日观察池（最多 3 只）与废票池  
4. 记录：是否违反「只做龙头 / 禁追后排 / 禁补仓」

## 6. 回测定义（研究口径）

若要用历史样本验证本策略，建议统一：

1. **妖龙样本**：区间内最大连板高度 ≥ 市场当月中位高度×1.5，或区间最大涨幅 ≥ 100%  
2. **入选日**：首次满足 `Score≥75` 且出现 B1/B2/B3  
3. **买入价**：断板日最低价，或分歧转一致次日开盘价（需预先声明）  
4. **出场**：S1–S6 先触发者  
5. **评价指标**：胜率、盈亏比、最大回撤、月度稳定性；按情绪阶段分层统计  

本仓库 `src/yaolong` 提供规则引擎与样本打分；实盘行情需自行接入数据源。

## 7. 一句话总纲

> **情绪定仓位，主线定方向，龙头定标的，换手定真假，席位做确认，买点只做三种，卖点无条件执行。**

这就是「跟随市场跟随资金」的可编码版本。
