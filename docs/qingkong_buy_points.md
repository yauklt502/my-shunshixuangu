## 1. 先看框架，再看买点

她的体系不是「看到金叉就买」。买点永远嵌在四层漏斗里：

```
市场环境（牛市急跌 / 震荡上行 / 事件减仓 / 轮动）
    → 主线（科技算力优先，热点只跟随）
        → 个股角色（底仓主线 / 波段 / 打地鼠 / 试盘）
            → 买点（急跌、企稳、启动苗头、飘旗、T、试盘）
```

口诀是她反复写过的：

- **不符合系统的行情坚决不做**
- **少追涨、多低吸**
- **不跌不动**
- **看好但不涨，先离场，等启动苗头**
- **宁可错过也不乱做**
- **不要满仓**

没有这六句，单独谈买点会变成追涨。

## 2. 个股买入点：七种合法动作

规则引擎代码：`B1`–`B7`。优先级不是「哪个更高级」，而是「这只票今天扮演什么角色」。

### B1 急跌低吸 / 日低加仓（最常用的开仓与加仓）

**公开原话对照**

- 「牛市急跌，好票跌的多，就逢低分批买」
- 「急跌深跌就加仓，恐惧中贪婪」
- 「能特科技日低加仓」
- 「持仓个股均补一成仓」
- 「数据港逢低分批加仓」
- 「回天、百傲持股做 T，逢低可少加」

**逻辑**

牛市框架里，急跌被当成**主线筹码的打折**，不是趋势结束。买的不是「跌得多」，而是「主线 + 已经持有或本来就在计划里的票 + 靠近当日低点或近几日深回撤」。

**触发（规则化）**

1. 环境是 `BULL_DIP` 或 `BULL_GRIND`，或你已经有底仓
2. 当日跌幅 ≤ -3%，或近几日最大回撤 ≤ -5%
3. 贴近日最低（日低加仓）或确认深跌
4. 标签落在科技/算力/她认定的主线，或本身就是持仓股
5. 仓位用「一成」这种小单元，禁止一次打满

**为什么这样买**

急跌把意志薄弱的筹码洗出去，主线资金往往在当日低点附近回补。她强调的是 **分批**，不是抄最低。买错的典型方式：非主线垃圾票也当急跌去接，或满仓去接。

**失效**

- 环境已经切到 `WEAK` / `EVENT_RISK`
- 这只票已经从主线降级
- 跌破她自己前面说的「企稳标准」还继续加 → 变成摊派

### B2 企稳确认（不跌不动）

**公开原话对照**

- 「利欧股份还是企稳确认中，不跌不动」
- 「利欧股份继续等待企稳，不知道企稳标准翻前面」
- 「可等明显右侧再交易」

**逻辑**

这是 **右侧买点**。横盘、阴跌、反复下探时，价格看起来便宜，但她明确禁止「因为便宜所以买」。要等：不再创新低、抛压减弱、计划里写过的企稳条件出现。

**触发**

- `consolidating=True` 且 `stabilize_ok=False` → **WAIT**，不是 BUY
- 企稳成立后再「分批少加」

**和 B1 的差别**

| | B1 急跌 | B2 企稳 |
|--|---------|---------|
| 情绪 | 恐慌、快速杀 | 磨、阴跌、方向未选 |
| 动作 | 分批接 | 空手等待 |
| 失败形态 | 接飞刀接到非主线 | 提前抄底抄成阴跌中继 |

利欧这种票在她笔下可以连续多日「不跌不动」，说明 **等** 本身就是买点系统的一部分。

### B3 启动苗头（先离场，再等信号）

**公开原话对照**

- 「看好就是不涨的股就暂时性离场，等有启动苗头再进」
- 「难道会出现届时天天涨停你买不进的情况？」

**逻辑**

时间成本比价格更重要。一只逻辑正确但不走的票，会把仓位锁死，让你错过真正启动的主线。她的解法不是死扛，而是 **清掉、盯着、启动了再进**。

这和「左侧埋伏」是反着的：她接受踏空一段，不接受把子弹压在死票上。

**触发**

- 持仓 + `liked_but_dead` → EXIT
- 之后出现放量转强 / 突破横盘上沿（`start_seed`）→ 再小仓 BUY

### B4 飘旗待涨（整理后的加速买点）

**公开原话对照**

- 「能特形成飘旗，有加速动能，待涨」

**逻辑**

旗形/收敛是主升中继，不是立刻加仓的理由。「待涨」= 承认加速概率上升，但 **突破前不加仓抢跑**。规则引擎里：有旗无突破 → `WAIT`；突破才允许小仓跟随。

这和打板体系的「一进二」不同：她等的是 **形态走完后的加速**，不是连板情绪。

### B5 打地鼠（快进快出，独立账户思维）

**公开原话对照**

- 「金通灵预判地鼠准确，大仓位快进快出」
- 「金通灵按操作纪律执行」
- 「恒信试盘，不符预期可离场」

**逻辑**

打地鼠不是低吸主线，是 **轮动脉冲**：猜对短催化，仓位可以比低吸更重，但持有周期按小时到 1–2 天计。猜错或脉冲结束，立刻清，不允许把打地鼠仓变成中线底仓。

**触发**

- 明确标记 `whack_a_mole`
- 允许相对更重的仓（默认上限 25%）
- `probe_failed` 或预期消失 → EXIT，没有「再看看」

**和 B1 的差别**

B1 错了可以按一成止损、主线还在还能等；B5 错了必须当天或次日处理，否则就是她说的过度交易借口。

### B6 持仓做 T（抖音作品真正对外的标签）

抖音标题「做做T十0」「来了，T」和淘股吧「持股做 T」对上了。她 2025-09-10 还发过《交易中如何做 T（第一节·基础知识）》，网页摘要是图片，正文无法在未登录情况下完整抓取。能确定的纪律来自每日计划：

- 先有底仓，再 T（回天、百傲、数据港、福龙马、博源、森麒麟都是「持股做 T」）
- 正 T 方向：急跌/日低先加浮仓，拉起来再把旧仓或浮仓对冲掉
- 仓位目的是 **降成本、把波段做顺**，不是把底仓做成超短
- T 飞了（利欧「又 T 飞了」这种评论）是系统代价，不是加仓理由

规则引擎要求 `has_core + t0_setup` 才给出 `Action.T0`。没有底仓的纯空单 T+0，不是她公开文字里的主做法。

### B7 试盘

**公开原话对照**：「恒信试盘，不符预期可离场」。

轻仓验证流动性、分时承接、板块是否同频。试盘失败不是「再补一成」，是离场。仓位默认 5%。

## 3. 卖点 / 减仓（买点的镜像）

买点没有配套离场就不是系统。她文字里出现过的离场不是均线公式，而是角色切换：

| 代码 | 情形 | 动作 |
|------|------|------|
| S1 | 拉高、涨停、仓重 | 止盈 **部分**，不是必清 |
| S2 | 打地鼠 / 试盘不符预期 | 清仓 |
| S3 | 阅兵等事件窗 | 先减总仓，停止新开 |
| S4 | 高标抱团大震荡 | 降仓，切到低价滞涨科技 |
| S5 | 「边打边撤」已有空间的票 | 高抛一部分，底仓可留 |
| S6 | 看好但不涨 | 暂时离场，等 B3 |

「青山纸业、利欧涨停止盈部分仓位」说明她的止盈默认是 **减码**，不是信仰式清仓。

## 4. 选股层：什么样的票才配谈买点

买点之前先过滤票。公开计划里反复出现的画像：

1. **主线**：科技、算力硬件「未来主线毫无争议」；固态电池、机器人、工艺母机是「跟随市场」的热点，不是信仰仓
2. **位置**：低价、涨幅不大、低位盘整、技术低位滞涨的细分龙头 —— 等风格切回绩优/科技时补涨
3. **不知道买什么**：买黄金 ETF（主题代理，避免乱点个股）
4. **复牌/外盘映射**：如中芯港股先跌，A 股复牌按补跌概率处理，不当普通低吸
5. **持仓数量**：「十全十美」≈ 10 只左右分散，靠数量降低单票情绪，而不是满仓 2–3 只赌命

硬过滤（代码 `hard_filter`）：ST、满仓、持股已满 10 只还开新仓、追涨价、一字买不到、标记为系统外。

## 5. 环境 × 买点（什么时候允许动手）

| 环境 | 含义 | 允许 | 禁止 |
|------|------|------|------|
| BULL_DIP | 牛市急跌 | B1 分批加主线 | 满仓、非主线抄底 |
| BULL_GRIND | 震荡上行 | B2 企稳、B4 待突破、B6 做 T | 追涨
| ROTATION | 热点轮得快 | B3、B5 打地鼠 | 一根筋死拿不涨的票 |
| EVENT_RISK | 阅兵/会议 | 只减、只 T | 新开仓 |
| WEAK | 缩量普跌 | 极轻或不做 | 把急跌当 B1 无脑加 |

2025-09-08 计划里还有一句操作总纲：**尽量少追涨，多低吸**；指数可以在区间里震，不要求每天都有新买点。

## 6. 用她自己的票把买点走一遍（形态对照，非荐股）

这些名字来自 2025-09 公开复盘，只说明「她当时把这只票放进哪种买点」。

1. **能特科技**：B1 日低加仓 + B4 飘旗待涨。同一只票可以先后处于两种买点，关键是阶段变了动作变。
2. **利欧股份**：长期停在 B2。可以做 T，但「企稳确认中」时现货开仓是等待。涨停后走 S1 部分止盈。
3. **数据港**：B1 逢低分批 + B6 做 T。典型「底仓 + 低吸」。
4. **金通灵**：B5 打地鼠，大仓快进快出；预判对了就走，不对就清。
5. **恒信东方**：B7 试盘，失败离场。
6. **青山纸业**：拉高/一字后是 S1，不是新的 B1。
7. **回天新材 / 百傲化学**：B6 持仓做 T，逢低少加，不是每天换股。

样本 JSON：`data/samples/qingkong_cases.json`，用这些形态做回归，避免规则引擎写着写着变成打板模型。

## 7. 和「打板买点」差在哪里

仓库里另有妖龙跟随（一进二 / 分歧转一致 / 断板首阴）。晴空这套 **不是** 那套：

| | 晴空（本文） | 妖龙跟随 |
|--|--------------|----------|
| 核心买点 | 急跌低吸、企稳、做 T | 一进二、回封、首阴 |
| 仓位哲学 | 十只左右分散、不满仓 | 1–2 只龙头 |
| 时间尺度 | 波段 + 日内 T | 连板情绪周期 |
| 最忌 | 追涨、死扛不涨的票、满仓 | 追后排一字、假点火 |

两套可以同时存在于研究库里，**不要混在同一笔交易里**：低吸主线的底仓，不应用打板的仓位去加。

## 8. 日常执行（按她的计划/复盘节奏）

**盘前**

1. 定环境：急跌 / 震荡 / 事件 / 轮动
2. 列持仓：每只只标一个角色（B1 可加 / B2 等待 / B4 待突破 / B5 纪律 / B6 可 T / 该减）
3. 新票最多试 1 个 B7 或 1 个 B5，禁止当天新开一串

**盘中**

1. 主线急跌才允许 B1，买在日低附近，一成一成来
2. 未企稳的 B2 票开着计划也不动手
3. 有底仓才 T；T 的浮仓当天处理
4. 打地鼠必须带着离场条件进场

**盘后**

1. 对照计划：加没加在日低、有没有追涨、有没有把打地鼠做成底仓
2. 写下一日一得里那句交易纪律（等待、降频、不硬抗）

## 10. 通达信选股公式

日线公式只能覆盖 **B1 / B2 / B3 / B4**。B5 打地鼠、B6 做 T、B7 试盘是盘中纪律，不要写进收盘选股。

完整可粘贴文本：

- 条件选股：`formulas/qingkong_tdx_xuangu.txt`
- 副图打点核对：`formulas/qingkong_tdx_futu.txt`
- 做 T 观察池（不是买点）：`formulas/qingkong_tdx_tchi.txt`

安装：通达信 → 功能 → 公式系统 → 公式管理器 → 条件选股 → 新建 → 粘贴选股公式 → 确定。选股时先圈定科技/电子/计算机/通信板块，公式本身不能判断「算力主线」。

若结果太多：把 `AMOUNT>80000000` 改大，或最后一行只保留一种买点，例如 `选股: B1急跌低吸;`  
若结果为空：先确认指数在 60 日均线上方（公式带牛市框架）；AMOUNT 单位若是万元，把阈值改成 `AMOUNT>8000`。

## 11. 局限

1. 抖音直播口播没有逐字稿，B6 的分时细节（黄白线、几格）**不能**冒充她的原话。
2. 淘股吧做 T 第一节是图片帖，未登录抓不到图内文字。
3. 「十全十美」、补一成、日低，都是她个人仓位习惯，换资金量必须自己缩放。
4. 2025-09 那一段是牛市框架下的低吸；换成熊市若仍按 B1 急跌加仓，会系统性亏钱。环境模块存在的原因就是这个。
5. 通达信选股是收盘形态近似，没有她盘中「日低」的分时精度，扫出来仍要人工看主线和仓位。
