# 竞价涨停取反 · 连板胜率优化说明

研究笔记，不构成投资建议。历史规律不保证未来收益。

## 一、原公式拆解

```
主板，非ST，竞价涨停取反，昨日涨停，
今日竞价量/自由流通股前5，
今日竞价量大于100万小于1000万，
竞价涨幅大于1%，
竞价量比大于8小于100，
今日竞价成交金额/昨日竞价成交金额大于0.8小于100，
竞价换手小于2
```

| 条件 | 意图 | 问题 |
|---|---|---|
| 主板非ST | 排除 20%/30% 板与垃圾股 | 合理保留 |
| 昨日涨停 + 竞价涨停取反 | 找「能上车的连板候选」，排除一字 | 核心逻辑对 |
| 竞价量/自由流通前5 | 短线资金关注度 | 单独排序偏粗，易选出巨量分歧 |
| 竞价量 100万~1000万 | 有流动性又不至于过度换手 | 上限偏松，800万以上常是砸盘 |
| 竞价涨幅 >1% | 情绪偏多 | 无上限：8%~9.9% 近似封死，取反意义弱，炸板风险高 |
| 量比 8~100 / 金额比 0.8~100 | 相对昨日竞价放大 | **上限几乎不起作用**，巨量分歧票也能过 |
| 换手 <2% | 控制竞价抛压 | 缺下限：极低换手=无人问津 |

原公式本质是「昨日涨停池里，开盘未封死、竞价相对活跃的前几名」。对 **连板晋级** 缺少：昨日封板质量、高度、流通市值、板块共振、以及 **9:15–9:25 走势形态**。

## 二、优化原则（面向连板）

1. **能买到**：继续 `竞价涨停取反`（开盘未封涨停）。
2. **有人抢但不乱**：竞价涨幅落在「强势可上车」区间，避开假强一字边缘。
3. **量能健康**：收紧量比/金额比上限，过滤巨量兑现。
4. **昨日板质量**：早封、少开板优先；尾盘偷袭/多次开板降权。
5. **高度可控**：优先 1→2、2→3、3→4；过高板样本少、波动大。
6. **盘前看走势**：9:20 后不可撤单段的抬升/回落，比单点 9:25 快照更能区分真假强。

## 三、优化后硬过滤（v2）

相对原版收紧处加粗：

| 维度 | 原版 | 优化 v2 |
|---|---|---|
| 竞价量（股） | 100万 ~ 1000万 | **100万 ~ 800万** |
| 竞价涨幅 | >1% | **1.5% ~ 7%** |
| 竞价量比 | 8 ~ 100 | **8 ~ 35** |
| 金额比 | 0.8 ~ 100 | **0.9 ~ 6** |
| 竞价换手 | <2% | **0.2% ~ 1.5%** |
| 连板高度 | 无 | **1 ~ 4** |
| 昨日炸板次数 | 无 | **≤1** |
| 流通市值 | 无 | **20亿 ~ 150亿** |
| 排名 | 量/自由流通前5 | 硬过滤后按 **综合分** 取前3~5 |

问财一句话见 `formulas/auction_zt_lianban_opt_iwencai.txt`。

## 四、综合分（排序用，不是硬砍）

在通过硬过滤后打分，默认取前 5（实盘建议前 3）：

| 因子 | 高分特征 | 低分/扣分 |
|---|---|---|
| 竞价涨幅 | 2.5%~5.5% | <1.5% 或 >7% |
| 量占自由 | 池内相对靠前 | 极靠前但伴随巨量金额比 |
| 昨日首次封板 | ≤10:00 | 尾盘偷袭 |
| 昨日开板次数 | 0 | ≥2 |
| 板块共振 | 同行业昨涨停≥3 | 孤岛题材 |
| 竞价走势 | 9:20 后抬升/高位放量 | 9:20 前冲高、9:20 后回落 |

## 五、9:30 前怎么选（竞价走势）

集合竞价分两段：

| 时段 | 规则 | 用法 |
|---|---|---|
| 09:15–09:20 | 可撤单 | 多虚假挂单；**只观察不决策** |
| 09:20–09:25 | 不可撤单 | **主决策窗口**：价格抬升 + 量加速 = 真强 |
| 09:25–09:30 | 撮合完成 | 最终确认；可挂开盘价/略高限价 |

推荐操作：

```bash
# 09:15 起轮询；09:20 后开始出「观察池」；09:25 锁定 Top
python scripts/preopen_pick.py --watch
```

走势标签：

- `升势确认`：9:20 后涨幅抬升 ≥0.3pct，且成交量递增 → 优先
- `高位横住`：价格在高位横盘，量不萎缩 → 可做
- `冲高回落`：9:20 前见高点，之后回落 ≥0.5pct → 剔除或降权
- `弱势磨底`：全程 <1.5% → 不进池

## 六、预期与边界

- 优化目标是提高 **连板候选质量密度**（少看垃圾分歧），不是保证晋级。
- 弱市/情绪退潮日：即使分数高也应降仓或空仓。
- 问财/通达信无法完整表达「9:20 后斜率」；盘前脚本才是完整方案。
- 自由流通用东方财富流通 A 股近似，与券商「自由流通」可能略有偏差。
