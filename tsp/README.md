# 先比独 · Tick Stock Panel

## 一键启动（Windows）

双击根目录 `一键启动.bat` / `START.cmd`。
- 第一次准备环境（仅一次）
- 第二次起直接开网页，不再下载


1. 下载最新 ZIP 并解压  
2. 双击根目录 **`START.cmd`**  
3. 装完依赖后会**自动打开** http://127.0.0.1:8765  
4. 黑窗口不要关

若之前失败过：删除 `tsp\.venv` 后再开。

说明：已去掉 `tdx-mcp` 强制依赖（它要求 Python≥3.12）。核心行情用 `eltdx`，Python 3.11 可正常安装。

## 功能

- 先比独策略选股
- 东方财富 / 同花顺 / 通达信可切换
- Tick Stock Panel：日K + 分时 + 1m/5m + 五档
- 复盘日期、一键截图、浅色主题
