【若双击启动没反应】请按这个顺序排查：

  1. 双击运行：CHECK.bat（或「诊断环境.bat」）
     - 看有没有找到 Python
     - 若弹出微软应用商店，说明没装真 Python

  2. 安装 Python 3.11 或 3.12（64位）
     https://www.python.org/downloads/
     ★ 必须勾选：Add python.exe to PATH
     ★ 安装后关闭所有黑窗口，重新打开文件夹

  3. 关掉 Windows「应用执行别名」里的假 python：
     设置 → 应用 → 高级应用设置 → 应用执行别名
     把 python.exe / python3.exe 开关关掉

  4. 双击：INSTALL.bat（安装依赖）
  5. 双击：START.bat（启动软件）← 推荐用这个英文名

  6. 若仍失败：打开同目录 start_log.txt，把内容发给开发者

【正常安装步骤】
  1. 解压本压缩包
  2. INSTALL.bat
  3. START.bat

【功能】
  - 刷新选股 / 一键截屏 / 导出 CSV
  - 数据源：东方财富（默认）/ 同花顺免费公开 / 通达信
  - 右上角圆点：绿色=已连接，红色=未连接（点一下可刷新）

【同花顺】
  - 已改用 10jqka 免费公开接口，无需任何 API Key
  - 离线可选：导出 CSV 放到 plugins\ths_export\

【通达信】
  - 导出 CSV 放到 plugins\tdx\export\
  - 或 .env 设置 TDX_HOME / TDX_PLUGIN_URL
