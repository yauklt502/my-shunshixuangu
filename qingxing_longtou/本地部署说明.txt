================================================================================
  清醒龙头战法 · 选股软件 —— 本地部署说明
================================================================================

【系统要求】
  - Windows 10/11（推荐，通达信/同花顺同机使用）
  - Python 3.10 / 3.11 / 3.12 / 3.13（64位）
    下载：https://www.python.org/downloads/
    安装时务必勾选 “Add python.exe to PATH”

【一键安装（推荐）】
  1. 解压本压缩包到任意目录，例如 D:\qingxing_longtou
  2. 双击运行：安装依赖.bat
  3. 双击运行：启动选股.bat

【手动安装】
  cd 到本目录后执行：
    python -m pip install --no-index --find-links=wheels_win -r requirements.txt
  若离线包不匹配你的 Python 版本，可联网安装：
    python -m pip install -r requirements.txt
  然后：
    python run.py

【功能】
  - 刷新选股：按「交易的清醒」龙头框架打分（聚焦/观察/回避）
  - 数据源：东方财富（默认）/ 同花顺 / 通达信
  - 一键截屏：保存到 screenshots\ 目录
  - 导出 CSV

【同花顺】
  - 在线：复制 .env.example 为 .env，填写 FUYAO_API_KEY
  - 离线：把导出 CSV 放到 plugins\ths_export\（见该目录 README）

【通达信】
  - 把插件/公式导出的 CSV 放到 plugins\tdx\export\
  - 或在 .env 中设置 TDX_HOME=你的通达信安装目录
  - 或设置 TDX_PLUGIN_URL=本地插件 HTTP 地址
  样例数据已在 plugins\tdx\export\，可先选数据源 tdx 试跑

【命令行】
  python cli.py --source auto --limit 20
  python cli.py --source tdx
  python cli.py --status
