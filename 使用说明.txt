短线寻龙 · 同花顺金融数据终端
================================

一、部署到 E 盘（推荐）
  1. 双击「一键部署到E盘.bat」
  2. 程序会复制到 E:\短线寻龙 并自动打开浏览器
  3. 以后日常使用：打开 E:\短线寻龙，双击「启动.bat」

二、不复制、直接在当前文件夹运行
  双击「启动.bat」即可。需要已安装 Python 3 或 Node.js。

三、首次使用
  1. 打开 http://127.0.0.1:8000/
  2. 到 https://fuyao.aicubes.cn/ 申请 API Key
  3. 把 Key 填进右上角输入框后回车（只存在本机浏览器，不写进源码）
  4. 点「连接测试」，成功后即可使用各模块

四、注意
  - 不要双击 web\index.html（file:// 会被跨域拦截）
  - 接口限频约 20 次/分钟，刷新过快会提示限流
  - 数据仅供研究参考，不构成投资建议

五、命令行启动（可选）
  python serve.py
  或
  node serve.js
