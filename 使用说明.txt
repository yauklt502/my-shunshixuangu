三条纪律看板 · 本地完整包
========================

请先解压，再进入文件夹。

【推荐启动】双击 START.bat
或双击 start.cmd
（若「启动.bat」无反应，请用上面两个英文名）

顶部可切换：
- 复盘日期（看历史涨停梯队）
- 数据源：东方财富 / 同花顺 / 通达信
- 低吸观察栏（代码逗号分隔；二三板点「＋」可加入）
- 软冻结% / 硬冻结%（控制③回撤冻结线）

① 低吸纪律：观察栏个股 + MA5 / 日内位置 → 可买入 / 观察 / 勿追高
② 二三板节奏：涨停梯队 + 可买入/观察标签
③ 回撤时别乱动：指数冻结 + 二三板/观察个股回撤列表（这就是个股区）

若刷新很慢：请更新到最新本地包。新版已取消逐票拉K线，①②③应在数秒内出数。

点击任意个股 → 弹出 Tick Stock Panel：
日K / 分时 / 1m·5m / 五档（强制通达信 TCP，不回退东财）

浏览器：http://127.0.0.1:5177/

本机需要 Python 3.10+ 或 Node.js。
通达信 TCP 默认：115.238.90.165:7709 （可用环境变量 TDX_HOST 覆盖）
