三条纪律看板 · 本地完整包
========================

下载后请先「解压」，再进入文件夹。

【推荐】双击 START.bat
也可以双击 启动.bat

窗口会显示启动过程，并停住方便看报错。

有 Python：
  [1/4] Creating / checking venv ...
  [2/4] Installing dependencies (first run 1-3 min) ...
  [3/4] Starting server ...
  [4/4] Browser will open automatically when ready.

没有 Python、有 Node：
  自动改用 Node（也可直接双击 start-node.cmd）

浏览器地址：http://127.0.0.1:5177/

本机需要二选一：
- Python 3.10+（安装时勾选 Add python.exe to PATH）
  https://www.python.org/downloads/windows/
- 或 Node.js LTS
  https://nodejs.org/

打不开时：
1. 必须先解压，不要在压缩包里双击
2. 优先双击 START.bat（英文名，最稳）
3. 看黑窗口报错，不要立刻关掉
4. 若 Python 失败：删掉目录里的 .venv 再开
5. 或双击 start-node.cmd
