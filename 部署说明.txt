============================================
  顺时选股 - Windows 部署说明
============================================

【重要】如果双击 .bat 没反应，请按下面「方法B」操作。

方法一：双击 deploy.bat（推荐，英文文件名更稳定）
----------------------------------------
1. 解压 ZIP 到任意文件夹（路径不要有中文）
2. 双击 deploy.bat
3. 部署完成后双击 start.bat
4. 浏览器打开 http://127.0.0.1:8000

方法二：PowerShell 部署（bat 无反应时用）
----------------------------------------
1. 在项目文件夹空白处 Shift+右键 -> 「在终端中打开」
2. 输入并回车：
   powershell -ExecutionPolicy Bypass -File install.ps1
3. 完成后双击 start.bat

方法三：中文脚本
----------------------------------------
1. 双击 一键部署到E盘.bat
2. 双击 一键启动.bat

安装目录（自动选择）：
  有 E 盘 -> E:\shunshi-trading
  无 E 盘 -> D:\shunshi-trading 或 C:\shunshi-trading

============================================
  常见问题
============================================

Q: WS 显示「未连接」？
A: 必须先运行 start.bat 启动后端，再访问 http://127.0.0.1:8000
   不要直接双击 frontend\dashboard.html

Q: 看不到「数据端口」下拉框？
A: 说明打开的是旧版 HTML。请通过 http://127.0.0.1:8000 访问看板。

Q: 双击 bat 闪退/无反应？
A: 1) 安装 Python 3.10+ 并勾选 Add to PATH
   2) 用方法二的 PowerShell 部署
   3) 右键 bat -> 以管理员身份运行

Q: 部署卡在 pip / Requirement already satisfied 很久？
A: 旧版会先升级 pip（从国外下载很慢）。新版已跳过 pip 升级，改用清华镜像。
   看到「首次安装 numpy/pandas」后等待 1-3 分钟即可，不要关窗口。
   若仍失败，用 PowerShell 运行 install.ps1。

Q: 数据端口选哪个？
A: 推荐「通达信 TDX」— 直连通达信服务器，无需 API Key（同源 tdx-mcp）。
   备选「东方财富」需网络可访问 eastmoney.com。

Q: 没有 E 盘怎么办？
A: 新版本会自动装到 D 盘或 C 盘，无需 E 盘。

Python 下载：https://www.python.org/downloads/
