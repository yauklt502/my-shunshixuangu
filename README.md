# 顺势选股 · 龙头确认

网页版实时龙头确认工具：一字板买不进，只作高度锚；真龙头看竞价与封板质量，输出今日最可能确认的两只非一字。

## 策略口径

1. **一字 = 高度锚**：记录市场高度，不进入可交易确认榜
2. **候选池**：昨日涨停且连板 ≥ 2（剔除 ST）
3. **确认信号**：竞价高开约 4%～9.5%、早封、零炸板、封单厚、真实换手
4. **主输出**：综合得分最高的 2 只非一字

## 启动

```bash
pip install -r requirements.txt
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

打开 http://localhost:8000

## API

- `GET /api/health` 会话状态
- `GET /api/leader` 龙头确认结果（可选 `?date=YYYYMMDD`）

数据来源：东方财富涨停池 / 昨日涨停表现 / 行情接口。仅供参考，不构成投资建议。
