# 龙虎榜弱转强 · 净买入分析

基于交易所公开龙虎榜，识别「当日大跌但榜面净买入」的弱转强形态，并给出次日观察清单。

锚定案例：**2026-08-03**

| 代码 | 名称 | 当日 | 净买 | 次日 | 五日 |
|------|------|------|------|------|------|
| 002409 | 雅克科技 | -9.63% | 4.90亿 | +7.09% | +28.39% |
| 002156 | 通富微电 | -9.50% | 2.23亿 | +8.30% | +23.10% |
| 301520 | 万邦医药 | -8.89% | 0.31亿 | +9.85% | +40.23% |
| 603118 | 共进股份 | -9.17% | 0.98亿 | +3.41% | +11.38% |

## 方法要点

详见 [`docs/lhb-buy-methods.md`](docs/lhb-buy-methods.md)。摘要：

1. **弱转强承接**：跌幅≤-7% 且龙虎榜净买>0（先排除弱势出货）
2. **净买占比**优先于绝对金额
3. **席位质量**：机构多家 / 北向 / 机构+游资合力
4. **共振要验大盘**：同日≥3只只是加分项；续跌日假共振胜率极低
5. **次日竞价验证**：榜面只做概率增强

## 样本结论（2026-06-01 ~ 2026-08-19）

- 大跌净卖对照：T+1 胜率约 36%，均值约 -1.8%
- 弱转强精筛（净买≥3000万 & 占比≥1.5%）：T+1 胜率约 57%
- 优质共振日（如 7/20、7/30、8/3）：T+1 胜率 85%~100%，且次日指数多数转正
- 劣质共振日（如 7/3、7/10、7/15）：T+1 胜率接近 0%，次日指数继续杀跌
