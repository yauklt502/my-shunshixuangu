# 先比独选股（Tick Stock Panel）

## 一键启动（和以前一样）

解压后 **双击 `一键启动.bat`**（或 `START.cmd`）即可。

- **第一次**：自动准备环境（仅一次，约 1–3 分钟）
- **第二次起**：不再下载，直接打开网页 http://127.0.0.1:8765
- 黑窗口请保持打开（关掉等于退出软件）

若以前失败过：删除 `tsp\.venv` 后再双击一次即可。

需要本机已安装 Python 3.10+（勾选 Add to PATH）。你当前的 3.11 可用。
