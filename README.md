# 顺势选股 · 龙头盯盘

## 小白怎么用

不用输入任何命令。

1. 下载压缩包并解压
2. 双击 `请先点我-安装到E盘.bat`（或 `INSTALL-TO-E.bat`）
3. 它会复制到 `E:\龙头盯盘`（没有 E 盘就放桌面），并自动打开浏览器
4. 以后每次：双击 `E:\龙头盯盘\打开盯盘.bat`

会弹出一个黑窗口，**不要关**。关掉就等于关掉盯盘。

## 判定规则

1. 选出当天最强三个板块（默认按涨幅）。
2. 过滤「昨日连板 / 历史新高」等统计池。
3. 板块内涨停优先：先封的是龙一。
4. 没有涨停按涨幅排。ST 不参与。

数据来自东方财富公开行情，只供看盘，不构成投资建议。
