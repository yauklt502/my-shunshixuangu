# 先比独选股（Tick Stock Panel）

## 一键启动

解压后双击 **`START.cmd`** 或 **`一键启动.bat`**

窗口会显示：
```
[1/4] Creating / checking venv ...
[2/4] Installing dependencies (first run 1-3 min) ...
[3/4] Starting server ...
[4/4] Browser will open automatically ...
```

成功后自动打开 http://127.0.0.1:8765  
**黑窗口请保持打开。**

若失败：删除 `tsp\.venv` 后再双击一次。
