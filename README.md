# 10秒定龙头 · 盘中跟 / 盘后盯

按同一套 6 步做裁判，**先定板块，再定票**。支线再猛也不进定龙池。

1. 今天主线是谁（涨停家数 + 成交额）
2. 主线里谁最先封、封得最死
3. 板块指数红不红、跟风有没有、炸了散不散
4. 大盘/板块回撤时谁最抗、谁先碎
5. 人气能不能叫出来（前三优先）
6. 最后看量：健康留下，一字或爆量见顶放弃

盘中输出：**只跟这一只**。  
盘后输出：**明天开盘只盯这一只，不在杂毛里找补**。

## 启动

```bash
./run.sh
```

Windows 双击 `start.bat`。打开 http://127.0.0.1:8765

页面可切「盘中跟 / 盘后复盘」，日期框复盘例如 `20260904`。

```bash
python3 -m dragon              # 按时段自动
python3 -m dragon --review
python3 -m dragon --intraday
python3 -m dragon 20260904 --review
```

## 近3个月回测

```bash
python3 -m dragon.backtest --start 2026-06-05 --end 2026-09-04
```

打开 http://127.0.0.1:8765/backtest 看对照表。数据来自选股宝历史涨停池（首封/炸板/换手/板块）和次日「昨日涨停」表现。

## 测试

```bash
python3 -m unittest tests.test_score tests.test_backtest -v
```

## 数据

东方财富：涨停池、炸板池、概念指数、人气榜、实时换手/成交额/量比、上证/深成/创业板指数。
