# 顺势选股 · 龙头盯盘

盯 **每日前三板块** 的 **龙一 / 龙二 / 龙三**。开盘后自动刷新涨幅、封板时间、连板高度、封单和开板回封。

数据来自东方财富公开行情（延迟接口），无需登录。

## 判定规则

1. 在概念、行业里选出当日最强三个板块（默认按涨幅；可改按涨停家数、成交额、主力净流入）。
2. 过滤「昨日连板 / 历史新高」等统计类板块，避免假热点。
3. 板块内 **涨停优先**：先封的是龙一；同一秒则连板高的在前，再比封单。
4. 没有涨停时，按涨幅、成交额排龙一龙二龙三。ST 不参与排名。

## 本地运行

```bash
npm install
npm test
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

生产构建：

```bash
npm run build
npm start
```

## 盘中用法

- 顶部切换 **综合 / 概念 / 行业**，以及排序口径。
- 三列对应当日前三板块，每列固定龙一、龙二、龙三。
- 涨停红条、炸板橙条；底部记录开板、回封、连板晋级、板块轮换。
- 点击股票或板块名称跳转东方财富行情。

周末和收盘后仍显示最近一个交易日的数据，刷新间隔会自动放慢。
