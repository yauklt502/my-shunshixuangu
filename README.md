# 先比独选股（Tick Stock Panel）

## 一键启动（Windows）

1. 重新下载并解压最新 ZIP
2. 进入内层文件夹，**双击 `START.cmd`**
3. 等待依赖安装结束，浏览器会自动打开 http://127.0.0.1:8765
4. **黑窗口不要关**

如果以前失败过：先删除 `tsp\.venv` 再启动。

需要 Python 3.10+（3.11 可用）。安装时勾选 **Add python.exe to PATH**。
