# A股短线博弈每日复盘系统 (A-Share Short-Term Speculation Review Tool)

## 📌 项目概述

本项目是一个专为 **A股超短线与短线龙头博弈选手** 量身打造的 **单文件离线 HTML 复盘量化工具**。

该工具基于真实公开行情数据，围绕 **情绪周期、绝对高位、低位试错、封单强度、主力资金、人气锚点与空仓检验** 七大核心博弈维度，为短线交易者输出全景式的周期研判、样本梯队、龙虎榜席位观察、次日集合竞价纪律与系统性风险提示。

所有 CSS 样式、JavaScript 逻辑与结构化行情数据 **全部内联于单个 HTML 文件** 中，无任何外部 CDN 依赖，在完全断网或内网环境下均可离线打开并流畅运行。复盘文件以 **交易日日期命名保存**（如 `2024-03-22.html`），便于长期归档、历史回溯及微调参数提升胜率。

## 🎯 核心功能与模块解析

### 1. 交易日与休市判定拦截 (Trading Day & Closed Market Verification)
- **非交易日安全拦截**：程序在加载时首先验证指定日期是否为正常交易日。
- **休市公告牌**：若所选日期为周末或法定节假日（如清明、五一、国庆、春节等），程序会立即展示高亮休市公告牌，说明休市原因、假期周期及下一交易日开市预告，并**终止场内行情计算与短线数据输出**。

### 2. 情绪周期判定与仓位温度计 (Sentiment Cycle & Position Thermometer)
- **四阶段演化模型**：量化识别 **启动/修复期**、**发酵/主升期**、**分歧期**、**退潮期**。
- **动态量化博弈得分 (0-100)**：综合连板高度、炸板率、连板晋级率、两市成交量及中位数涨幅实时计算。
- **仓位防守指引**：明确建议当前周期仓位（如 0~2成严格防守 / 2~4成试错 / 5~7成主线进攻 / 8~10成满仓抢筹）。

### 3. 绝对高位空间锚定与低位试错 (Absolute High & Low-Level Trial)
- **最高空间板深度拆解**：追踪全市场最高连板龙头（如 13连板艾艾精工、15连板双成药业、20cm 5连板蓝盾光电等）的代码、分时形态、封单状态及异动规则。
- **高位负反馈雷达**：监测天地板、跌停炸板与核按钮大面风险。
- **持筹 vs 持币纪律**：输出针对龙头股持筹者第一卖点、持币者试错节奏的明确操作指引。

### 4. 样本梯队矩阵与连板身位图 (Sample Ladder Matrix)
- **全景梯队展示**：完整展现高位板、5板、4板、3板、2板及精选首板。
- **多维盘口数据**：最新价、涨跌幅、核心题材概念、成交额、换手率、封单额、封成比、封板时间与盘口定性标签。

### 5. 封单强度与涨停质量评估 (Sealing Strength & Quality Analysis)
- **封单强度排行榜**：展示封单金额、封成比（封单额/日成交额）、自由流通比及首封时间。
- **次日溢价预测模型**：评估一字秒板、爆量实体突破板与烂板回封的次日竞价溢价概率。
- **炸板大面股票归因**：直观展示冲高回落被砸个股的异动归因与中位接力风险。

### 6. 主力资金流向与市场人气锚点 (Capital Flow & Popularity Anchors)
- **行业/题材资金榜**：主力净流入前列板块（含涨停家数与领涨龙头） vs 净流出承压板块。
- **百亿人气中军锚点**：深度解析赛力斯、万丰奥威、东方财富、润和软件、中信海直等超级流动性风向标的角色定位与支撑效应。

### 7. 龙虎榜顶级游资与机构观察 (Dragon & Tiger List)
- **游资操盘画像**：追踪六一路、呼家楼、作手新一、方新侠、机构专用席位等席位的买卖动向与席位溢价/砸盘逻辑。

### 8. 空仓检验 7 大铁律 (Cash Defense Checklist)
- 提供 7 项严格量化红线检测：
  1. 高位总龙头断板跌停/恶性负反馈
  2. 市场炸板率超过警报线
  3. 连板晋级率跌破冰点阈值
  4. 日内大幅回撤/天地板数量超标
  5. 指数破位且成交量严重萎缩
  6. 题材一日游轮动与前日涨停次日大幅计提
  7. 处于情绪退潮期第二阶段杀跌

### 9. 胜率参数与量化模型微调 (Parameter Tuning & Optimizer)
- 用户可点击页面顶部的 **「⚙️ 胜率参数设定」** 弹窗，自定义微调：
  - 炸板率警报阈值 (默认 30%)
  - 连板晋级率冰点阈值 (默认 35%)
  - 强封单封成比阈值 (默认 50%)
  - 大盘量能萎缩预警线 (默认 8000 亿)
- 保存后全站各项指标、周期判定、空仓得分与建议仓位将**实时动态重新计算**并持久化保存。

## 🚀 使用与构建说明

### 直接使用
双击打开任意 `.html` 文件即可在浏览器（Chrome / Edge / Firefox / Safari 等）中直接使用，支持快速切换不同交易日或非交易日测试，支持一键打印/导出 PDF 报告。

### 🖨️ 导出打印与另存为 PDF 复盘简报
本工具已对打印排版（`@media print`）进行了深度优化，自动隐藏操作控件、自动换页防截断，并将暗色主题智能转换为高对比度、节省墨水的专业纸质报告版式：

1. **方式一：点击页面按钮一键触发**
   - 在页面顶部右侧，直接点击 **「🖨️ 导出/打印复盘」** 按钮，浏览器将自动弹出系统打印对话框。
2. **方式二：使用键盘快捷键**
   - Windows / Linux：按下 `Ctrl + P`
   - macOS：按下 `Command + P`
3. **另存为 PDF 最佳设置建议**：
   - **目标打印机 (Destination)**：选择 `另存为 PDF` (Save as PDF)。
   - **方向 (Layout)**：选择 `纵向` (Portrait)。
   - **纸张尺寸 (Paper size)**：选择 `A4`。
   - **背景图形 (Background graphics)**：勾选此项（以完整保留涨跌红绿高亮与状态徽章）。
   - **页眉和页脚 (Headers and footers)**：建议取消勾选，以获得更干净的报告外观。
   - 点击 **「保存」** 即可输出一份排版精致的 PDF 复盘简报。

### 🔄 重新构建 / 扩充数据集
若需增加更多历史交易日数据，可直接编辑 `build_review_tool.py`，然后运行构建脚本：
```bash
python3 /workspace/generator.py
```
构建器将自动输出包含最新数据的全套独立单文件 HTML。
