# 三条纪律看板

把抖音连麦干货里的三件事写成可执行纪律，并用免费实时行情做真实体现：

1. **低吸纪律** — 看观察票在日内高低点的位置（可贴低 / 观望 / 勿追高）
2. **二三板节奏** — 看今日涨停梯队（二板、三板数量与情绪结构）
3. **回撤时别乱动** — 看上证/创业板相对近高点回撤，触发软/硬冻结

## 数据源（可切换）

| 选项 | 说明 |
|------|------|
| 东方财富 | `push2.eastmoney.com` 免费行情 / 涨停池 |
| 同花顺 | `d.10jqka.com.cn` + 涨停池 API |
| 通达信兼容（腾讯） | `qt.gtimg.cn` 免费行情（通达信常用同源公开源）；K 线走新浪；涨停池回退同花顺 |

任一源失败会自动回退到其他可用源。

## 启动

```bash
npm install
npm start
```

打开 http://127.0.0.1:5177

## 功能

- 数据源下拉切换
- 自定义低吸观察股票代码
- 15 秒自动刷新
- **一键截图**（白底导出 PNG）
