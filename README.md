# 真龙识别 · 盘中盯盘卡

在原版「真龙识别」收盘卡（深色 `index.html` / 浅色 `真龙识别_20260903.html`）上接入公开行情，**版面和四特征逻辑保持不变**，可盘中刷新、翻历史、一键截屏。

## 怎么用

```bash
python3 server.py
```

浏览器打开 http://127.0.0.1:8765/

- **日期**：查看历史交易日。2026-09-03 默认用精选快照（与原卡一致）。
- **刷新 / 今日**：向东方财富涨停池 + 实时行情重新验货，盘中也可点。
- **盘中自动**：勾选后每 30 秒拉一次当日数据（仅当天）。
- **一键截屏**：导出当前盯盘卡 PNG（不含顶栏）。
- **浅色 / 深色**：两套皮肤对应你原来的两份 HTML。

也可以 `?date=2026-09-03&theme=light` 打开指定日。

直接双击 HTML 也能看 9/3 快照和截屏；要翻其他日期或盘中更新，需要先启动 `server.py`。

## 评分口径（未改）

带动性 / 领涨性 / 渡劫能力 / 顶级流动性，0 / ½ / 1，任一为 0 即非龙。退潮期一票否决、空仓优先。

数据来自东方财富公开涨停池、跌停池、炸板池、昨日涨停与指数行情，仅作纪律清单，不是荐股。
