# 同花顺 / 通达信 · 首板竞价选股（≤5只）

集合竞价结束（9:25）后、9:28 前运行。买入价按 9:30 开盘（≈竞价成交价）。
**不要竞价一字涨停**：开盘价触及涨停的全部过滤。

最终参数以 `results/best_report.json` 与 `formulas/` 为准（回测写入）。

## 交易规则（回测口径）

1. 股票池：昨日**首板**（收盘涨停且前一日未涨停）。剔除 ST、科创板、北交所、昨日一字板。
2. 9:25 后看竞价：开盘涨停 / 开盘跌停不买。
3. 再按流通市值、量比、竞价涨幅、昨日首板家数过滤，排序后取 ≤5 只。
4. 9:30 买入；盘中止盈/止损（若公式启用）否则收盘卖出。
5. 回测含约 0.15% 往返成本。

胜率是历史回测结果，不保证实盘。
