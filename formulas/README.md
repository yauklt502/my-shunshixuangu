# 使用说明

## 什么时候选

每个交易日 **9:25 集合竞价结束之后、9:28 之前** 运行公式。开盘价此时已是竞价成交价。

## 买什么

昨日 **首板**（收盘涨停且再前一日不是涨停），今日竞价 **低开 2%~8%**，且不是一字/涨停/跌停。

排除：ST、科创板、北交所、昨日一字板、流通市值不在 25~100 亿、昨日量比不在 0.8~5。

上证/对应指数竞价跌幅超过 2% 时空仓。

多个标的时按 **竞价涨幅从低到高** 排，取 **3 只**（硬上限 5 只）。

## 怎么交易（回测口径，必须一起用，否则胜率到不了 70%）

| 步骤 | 规则 |
| --- | --- |
| 买入 | 9:30 开盘买（≈竞价价） |
| 止盈 | 立即挂 **买入价 +1.5%** 限价卖单 |
| 未止盈 | **收盘卖掉**，不做盘中止损 |
| 成本 | 回测已扣往返约 0.15% |

只选股、拿到收盘，胜率大约 50%，不是 85%。高胜率来自 **低开首板的盘中反抽止盈**。
