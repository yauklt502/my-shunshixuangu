# 按截图尽量复现的两套公式

两张图是 9/1 09:54 看盘。图1 自选「更新于 08-31 09:37」，价是 9/1 实时价，选股条件要用 **8/31 的开盘/竞价**。

## 图1（截图 49 只）→ 竞价高开 2%–9% 再加价、市值、量比

通达信：`posted_jingjia_2to9.txt`  
问财：`非ST，今日开盘涨幅2%到9%，股价大于等于11元，流通市值大于25亿，量比大于0.7`

8/31 回放：**48 只**（贴近 49）。截图里能核对的 8 只沪深 **全中**：捷荣、登海种业、国光连锁、天山生物、瑞芯微、招商港口、辰安科技、美力科技。科创博瑞医药开盘 +4.7%、量比 0.77，也符合。北交百甲科技流通市值约 6 亿会漏，秋乐种业市值够有机会进。

选出后按 **涨幅从大到小** 排，和自选一样。

## 图2（截图 7 只）→ 昨日涨停晋级

通达信：`posted_yest_zt.txt`  
问财：`非ST，主板，流通市值25亿到80亿，昨日涨停，今日开盘涨幅大于5%`

再加：**(昨日连板>=2 或 今日开盘涨停)**，去掉创业板/科创/北交。

9/1 回放：**11 只**，截图 7 只 **全中**：新赛股份、我爱我家、海鸥住工、万向德农、福建金森、中广天择、捷荣技术。  
多出 4 只同类票：欢瑞世纪、国芳集团、大晟文化、时代出版。按涨幅排也在最前，同一类「昨日涨停今日冲板」。

海鸥住工、福建金森、中广天择、新赛股份是竞价一字，公式会选出来但买不进。
